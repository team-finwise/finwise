# FINWISE — Project Specification

## 1. Problem

Young adults often struggle to understand how their income, expenses,
savings, debt and financial goals interact.

Financial information is often available, but it is difficult to turn
that information into a clear and actionable personal plan.

## 2. Proposed Solution

FINWISE is an AI-powered personal financial planning assistant that
analyzes a user's financial profile and helps them understand their
financial position, plan goals and explore hypothetical scenarios.

## 3. Target Users

- College students
- Young professionals
- Individuals beginning financial planning

## 4. Core Features

### Financial Profile
Collect income, savings, expenses and debt information.

### Expense Analysis
Analyze spending patterns and categorize major expenses.

### Financial Goals
Allow users to define financial goals with target amounts and dates.

### Financial Analysis
Generate a structured overview of the user's financial position.

### What-If Analysis
Allow users to change variables such as income or expenses and observe
the projected effect on their financial goals.

### Financial Education
Explain financial concepts and the reasoning behind generated insights.

## 5. Build It Technologies

Primary:
- PartyRock
- Strands Agents SDK

Potential:
- OpenSearch

## 6. Project Principle

Financial calculations should be deterministic wherever possible.
AI should primarily be used for interpretation, explanation and
personalized planning rather than basic arithmetic.
